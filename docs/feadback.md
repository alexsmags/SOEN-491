# Peer Feedback Summary

Three users tested the application to evaluate usability (done locally on their computer), features, and performance.  
The following feedback and improvement points were identified during the review.

## Summary of Findings

### 1. Unsaved Edits Warning  
All 3 testers noted that unsaved edits were lost when navigating or refreshing the page.  
A warning prompt was requested to prevent accidental data loss.

### 2. Custom Color Picker  
2 testers suggested adding a color picker for font and background customization in the editor,  
as users were limited to predefined color options.

### 3. Page Refresh on Tab Switch  
A tester observed that switching browser tabs caused the page to reload,  
resulting in lost progress or configuration.

### 4. Emoji Support in Caption Generation  
Testers found that enabling “Include Emoji” did not actually add emojis to generated captions.  
An update to include emoji support was recommended.

---

All four issues were documented as separate tickets for tracking and later resolved based on this feedback.
